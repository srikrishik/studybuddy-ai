\# Contributing to StudyBuddy AI



Thank you for your interest in contributing to StudyBuddy AI! 🎉



StudyBuddy AI is an open-source AI-powered personal study companion. Contributions that improve the project, fix bugs, improve the user experience, or add useful learning features are welcome.



\## 🚀 Getting Started



\### 1. Fork the repository



Fork the StudyBuddy AI repository to your own GitHub account.



\### 2. Clone your fork



```bash

git clone https://github.com/YOUR-USERNAME/studybuddy-ai.git

cd studybuddy-ai
